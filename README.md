# Muni University Service Directory

This application helps lecturers, students, and visitors locate places and services on campus more easily.

## Features

- **Search:** Find a service or place by name.
- **Category filtering:** Narrow the list by service category.
- **Opening status:** See whether a service is displayed as open or closed, based on the device’s time.
- **Directions:** View location or direction details for a place.
- **Feedback form:** Enter feedback through the website.

## Technologies Used

The directory uses HTML for the webpage structure, CSS for styling, and JavaScript for interactivity.

## Setup and Running

1. Download the project from GitHub as a ZIP file.
2. Extract the ZIP file and keep the files and images together.
3. Open `index.html` in a web browser.
